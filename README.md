# Saanidhya — Old Age Home & Assisted Living Website

A responsive seven-page front-end website concept.

## Pages
1. `index.html` — Home
2. `home-2.html` — Home 2 (premium/resort-inspired direction)
3. `about.html` — About
4. `living-options.html` — Living Options & Virtual Tour
5. `medical-care.html` — Medical & Nursing Care
6. `daily-life.html` — Daily Life & Activities
7. `contact.html` — Contact and family enquiry

## Features
- Responsive layout designed for mobile (300px+) through desktop.
- Functional hamburger navigation for tablet/mobile.
- Active-page navigation state.
- Dark/light mode toggle.
- RTL layout toggle.
- Family enquiry form with front-end demo confirmation.
- Two distinct home page concepts.
- Shared CSS and JavaScript.

## Run
Open `index.html` in a browser. Internet access is required for Google Fonts and remote Unsplash sample photography.

## Important launch checklist
This is a front-end demo, not a live care-provider website. Replace all sample phone numbers, email addresses, address, map, visiting hours and images with verified details. Connect the enquiry form to a secure backend and add a privacy notice before collecting personal information.

Verify every service claim before publication, including doctor availability, nursing coverage, emergency response, hospital/ICU tie-ups, rehabilitation, specialist memory care, room inventory and accessibility specifications. Do not publish certifications, staffing ratios or medical capabilities unless documented. Confirm all fees, deposits, included services and additional charges in a transparent fee schedule. Obtain consent for resident photographs, testimonials and stories.

The brochure CTA currently directs visitors to the enquiry section; add an approved downloadable brochure once the content is final.
